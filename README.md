# Symbiologic

**Transforming complexity into human-centered clarity.**

The website for Symbiologic, a Tampa studio for human-centered design, quantum-ready security and responsible AI.

## Run it
It's a static site: open `index.html` in a browser. It is published with GitHub Pages from the `main` branch.

## Files
- `index.html`: the whole page (HTML and CSS)
- `assets/`: logo, favicon and photos
